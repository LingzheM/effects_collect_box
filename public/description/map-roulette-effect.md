**「Map Roulette」** —— 一个用 **JavaScript + GeoJSON + SVG** 制作的趣味国家随机选择器界面（Map Roulette）。

### 主要 Effect 效果描述：

- **核心“Spin” 机制**：
  - 点击蓝色 **SPIN** 按钮后，左侧国家列表会**快速滚动**（像老虎机或轮盘），伴随**平滑减速**停止在随机选中的国家上（高亮红色）。
  - 同时，右侧世界地图上对应国家会**瞬间高亮填充为红色**，视觉反馈非常直接且同步。

- **流畅的地图交互**：
  - 高亮国家后，可点击 **ZOOM** 按钮，地图**平滑放大**聚焦到选中国家（从世界地图 → 区域特写）。
  - 点击 **WORLD** 按钮可快速复位回全球视图。
  - 地图使用 SVG 渲染，线条清晰，支持快速切换。

- **细节面板（Details）**：
  - 选中国家后，下方立即展示：
    - 国旗（动画出现或切换）
    - 国家名称
    - 人口、首都、面积、洲别、货币、语言等关键信息
  - 所有切换过程都有**淡入 + 轻微动画**，信息布局清晰整洁。

- **整体界面质感**：
  - **极简现代设计**：干净的白色/浅色背景， typography 优秀。
  - **丝滑微交互**：按钮 hover 效果、列表滚动惯性、地图高亮过渡都处理得非常舒服。
  - 动画节奏感强，Spin 过程有明显的“随机感”与“期待感”，类似赌博轮盘或 gacha 机制。

这是一个**趣味性 + 实用性结合**的界面 demo，作者提到后续可能用于帮自己随机选电影、餐厅等场景。技术栈轻量（纯 JS + SVG），性能优秀，适合网页端直接使用。

整体风格干净、专业又带点玩乐性，交互体验很愉悦！
