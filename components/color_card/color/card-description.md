# 三个独立的层

1. 底层 (Back Flap): 文件夹后盖。
2. 中间层 (Card)：文件夹中的卡片。
3. 前盖 (Front Flap)：绕着左轴转动文件夹封面。

# 任务5.1：建立层叠秩序（Introduce Layers & Z-index）

- 核心动作：在`BookCover`中添加一个静态的`div`作为最底层，并给前/中/后三层分别赋予3,2,1的`zIndex`.

- 预期效果：点击打开时，你会在卡片滑出的地方看到一个固定的蓝色"底座"，制造出一种“文件被夹在中间”的视觉。

# 任务5.2: 修复"前盖消失"与重排轨迹

- 核心动作：删除前盖的`backfaceVisibility: 'hidden'`，并将旋转角度限制在更自然的-130度内；同时，加大卡片滑出的位移，制造穿插感。

- 预期效果：点击后，前盖（侧着），滑出来的白色卡片，以及底下的静态后壳都清晰可见。
